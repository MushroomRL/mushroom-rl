Air hockey
==========

The air hockey tasks: a planar robot has to hit, defend, prepare or repel a puck on a table. ``AirHockeyBase`` is
the abstract base of the family, ``AirHockeySingle`` and ``AirHockeyDouble`` set up the one- and two-robot tables,
and each task defines the initial puck state, the reward and when the episode is over.
